# Forth Operative System

## What is this project made for?

This is a study project, as I am trying to learn OSDev.

## What does the project have right now?

Right now, the project has:

* Basic output with VGA (driver: kernel/drivers/vga.c)
* Basic common headers for I/O with ports (file: kernel/common_headers/io.h)

## What are the next steps?

I am working on:

* PS/2 driver for keyboard (with interrupts)
* Primitive printf

## Contributing

Feel free to contribute to the project by adding your own drivers, functions or by fixing bugs!
